# splits/ —— 固定划分与半监督子集

本目录是论文 CADJ-26-00448 返修意见 **R2-Q2** 的交付物：数据集固定划分、
每类计数、有效性过滤、近重复检查，以及半监督实验所需的有标签 / 无标签子集。

## 文件说明

| 文件 | 说明 |
|---|---|
| `../make_split.py` | 生成本目录全部文件的脚本（仅依赖标准库） |
| `train.txt` / `val.txt` / `test.txt` | 固定划分，每行一个模型 ID，LF 行尾 |
| `excluded_models.txt` | 被有效性过滤剔除的模型及原因 |
| `split_report.md` | 划分统计报告（每类模型数 / 实例数 / 面数 / 底面数） |
| `labeled_r*.txt` / `unlabeled_r*.txt` | 半监督「有标签比例」子集，比例为 1 / 5 / 10 / 20 / 50 / 100% |
| `ratio_report.md` | 各比例下的类别覆盖表 |
| `occ_bbox_scan.csv` | 全量 OCC 包围盒扫描结果（有效性过滤的原始依据） |
| `scan_occ_bbox.py` | 生成 `occ_bbox_scan.csv` 的脚本（需要 OCC 7.5.x） |

## 复现方式

```bash
# 1) 全量扫描 BRep 包围盒（需要 OCC 环境，约 3 分钟 / 8 进程）
python splits/scan_occ_bbox.py

# 2) 生成划分与半监督子集
python make_split.py \
    --root   /path/to/myNewDatasets \
    --out    ./splits \
    --ratios 0.7,0.1,0.2 \
    --seed   42 \
    --bbox-csv ./splits/occ_bbox_scan.csv --bbox-threshold 100 \
    --ratio-subsets 0.01,0.05,0.10,0.20,0.50,1.00 --ratio-seed 0
```

## 关键设定

### 1. 类别约定

语义类别共 30 个（`--num_classes 30`）：

- **0–26**：27 个加工特征类；
- **27 / 28 / 29**：`plane` / `cylinder` / `cone`，即**毛坯基体面（背景类）**。

背景类在训练与评测中被掩码（`models/brepseg_model.py` 的 `non_feature_classes`，
由 `--num_non_feature_classes 3` 控制），**不产生语义损失、不计入 mIoU**。
本数据集毛坯为长方体，因此只有类 27 实际出现，类 28 / 29 保留但计数为 0。

### 2. 划分方式：按结构同构组分层

「结构签名」= (面数, 实例数, 实例尺寸序列, 每类面数) 四元组全部一致。
同一签名的模型视为一组，**整组一起进入同一个划分**。

- 随机划分下，跨 train/test 的结构孪生组为 **710**；
- 按组划分后为 **0**。

比例 70 : 10 : 20，随机种子 42。

### 3. 有效性过滤（共剔除 316 个，1.07%）

| 原因 | 数量 | 说明 |
|---|---|---|
| `missing_bin` | 297 | 缺少预处理后的 `.bin` 文件，无法参与训练 |
| `bbox_extent_gt_100mm` | 19 | BRep 包围盒最长边超过 100 mm |

第二类的原因：预处理 `multi_StepToBin.normalize_shape` 用 `BRepBndLib.Add` 取包围盒，
对含 BSpline（圆角 / 过渡）面的模型会按**控制极点**估算，实测最大高估 **167 倍**
（9066 mm vs 真实 54 mm），导致该模型在 bin 里被压成一个点。
毛坯 x / y / z 各为 `uniform(10, 50)` mm，加工特征只做材料去除，
故包围盒最长边不可能超过 50 mm —— 阈值取 100 mm 已很宽松。

> 注：62 个模型的 `Add` 包围盒超阈值，其中 43 个本身就没有 bin 文件（两者高度相关）；
> 另有 15 个模型的 `AddOptimal` 包围盒也超阈值，属几何本身异常。

### 4. 半监督「有标签比例」子集

协议与两篇参考文献一致：

- **数据池固定** = 训练集全体（20 420 个模型）；
- **无标签池** = 训练集减去有标签子集，随比例变化，由固定种子决定；
- **不额外生成无标签数据**；
- 有标签子集按比例**随机**抽取，子集大小严格等于 `round(比例 x 20420)`；
- 额外加一层「每个加工特征类至少 1 个模型」的覆盖保证（实测 r = 1% 时随机抽样
  已覆盖全部 27 类，最稀有类期望 14.2 个模型，该保险通常不触发）。

实测各比例下**缺席类别数均为 0**，最小类模型数分别为 9 / 61 / 126 / 251 / 703 / 1418。
